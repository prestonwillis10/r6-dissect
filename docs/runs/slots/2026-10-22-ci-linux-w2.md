## Candidates

### setup-go v7.0.0 keys the module cache on go.mod, not go.sum

Observed: `raw.githubusercontent.com/actions/setup-go/b7ad1dad31e06c5925ef5d2fc7ad053ef454303e/src/package-managers.ts` contains `dependencyFilePattern: 'go.mod'`; `src/cache-restore.ts` hashes `findDependencyFile(packageManagerInfo)` unless `cacheDependencyPath` is set; the README at that SHA says "By default, the cache key for Go modules is based on `go.mod`. To use `go.sum`, configure the `cache-dependency-path` input." The spec premise (cache cannot find `go.sum`) is therefore not the mechanism: the old ordering failed because `go.mod` was absent before checkout. The new ordering fixes that, so the cache key resolves. A change confined to `go.sum` (checksum-only) would not rotate the key.
Acceptance: add `cache-dependency-path: go.sum` to the three `setup-go` steps in `.github/workflows/build-test.yaml` (`cache: true` lines) if checksum-only rotation is wanted, and confirm the second run logs a `Cache restored from key:` line.
