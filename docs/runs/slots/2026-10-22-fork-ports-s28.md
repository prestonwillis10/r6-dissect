## Deviations from the plan

- The plan says 11 of the 12 fixture JSONs change. The valid fixture JSON count at bd6ccbe and at f30b152:
```
$ git ls-tree -r --name-only bd6ccbe -- dissect/test/data/replays/valid | grep -c '\.rec\.json$'
11
$ git ls-tree -r --name-only f30b152 -- dissect/test/data/replays/valid | grep -c '\.rec\.json$'

```
  The diff stat under Goldens lists the changed files; the keys-deleted check has the kill count and the slot split.
- The plan's `killPacket` test input appends a `0x00` byte to avoid an EOF at the end of the buffer.
